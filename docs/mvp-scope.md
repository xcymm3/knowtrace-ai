# CommerceLens AI MVP 范围

## 解决的问题

电商运营在选品和竞品调研时，往往需要在商品表格、截图、品牌手册、评价摘要和平台规则之间来回切换。CommerceLens AI 将这些材料统一归档、检索和引用，帮助团队形成可复核的选品结论。

## 首期用户

- 电商运营：维护候选商品池、发起调研、阅读报告。
- 类目负责人：确认优先级与风险提示。
- 设计/内容协作人员：读取被确认的卖点策略，不负责在本 MVP 内生成视觉素材。

## 首期能力

- 调研项目与商品/竞品记录。
- 资料上传、文件解析与任务进度。
- 基于 Supabase pgvector 的语义检索和证据引用。
- 多商品横向对比与选品报告。
- 人工确认、驳回和反馈沉淀。

## 明确不做

- 图片生成或第三方生图 API 集成。
- 未授权电商平台页面抓取。
- 自动投放、自动定价、自动下单。
- 多租户计费、企业级 SSO 与复杂权限。
